# 📸 Ksenia Dubrovskaya — Photographer Portfolio

Premium portfolio website for photographer **Ksenia Dubrovskaya**.

A modern, responsive portfolio with a luxury dark design, created to showcase portrait, fashion, lifestyle and actor photography.

---

## ✨ Features

- Full-screen Hero section
- Dark Luxury design
- Responsive layout
- Portfolio gallery
- Lightbox image viewer
- Smooth scroll animations
- About section
- Pricing section
- Contact buttons (Instagram / Telegram / WhatsApp)
- SEO-friendly structure

---

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- GLightbox
- AOS (Animate On Scroll)
